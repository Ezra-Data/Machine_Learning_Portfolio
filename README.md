# Ezra Ndinya Ogechi — Portfolio Website

Personal portfolio website for **Ezra Ndinya Ogechi**, Data Scientist and Machine Learning Engineer.

The production Next.js web application is located in the [`portfolio-app`](./portfolio-app/) directory.

## 🚀 Running the Site Locally
```bash
cd portfolio-app
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000)
